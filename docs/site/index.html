AgentSemaphore

One dot next to your clock that tells you which AI agent needs you.

Stop watching agent windows. Turn the notification noise off. Look at the dot. Free and open source (MIT), runs locally, no accounts, no telemetry.

Install Source on GitHub Releases
Pre-alpha. Things will break and formats will change. It has been tried on only a handful of machines. If you try it, you are warmly invited to report what you see or to contribute.

The real program on a Linux desktop panel (XFCE) with three example sessions: the dot, its tooltip and its menu.

The four colours

Red

An agent is blocked waiting for you: a question, a permission, a plan to approve.

Grey

Unknown: a source could not be read, so a red might be hidden. It never pretends to be green.

Orange

An agent is working and does not need you.

Green

All quiet. Nothing is waiting for you.

The worst state across all sessions wins. Hover the dot for a summary, open its menu for the list of sessions.

How it works

  • Read-only. For Claude it reads what Claude already writes. For Copilot, Codex and Gemini CLI it adds an observer hook only when you ask for it.
  • Local and private. No accounts, no servers, no telemetry. Nothing leaves your machine.
  • Fails soft. If a format changes upstream, the dot turns grey and says which source; never a wrong green.

Install

Windows (x64 and ARM64)

Per user, no admin rights, PowerShell 7. From a clone of the repository:

pwsh -File install/windows/install.ps1 -FromRelease -Autostart

It also installs agentsemaphore-cli.exe, the console build for commands in a terminal and for agent hooks.

Or with Scoop (from v0.1.0-alpha.4; use the newest release tag):

scoop install https://github.com/LuisPuertollano/AgentSemaphore/releases/download/v0.1.0-alpha.4/agentsemaphore.json

It downloads the newest release for your machine and checks its SHA-256. Add -WhatIf to see every change first.

Linux and macOS

Per user, no sudo:

curl -fsSL https://raw.githubusercontent.com/LuisPuertollano/AgentSemaphore/main/install/unix/install.sh | bash -s -- --autostart

On GNOME the dot needs the AppIndicator extension (Ubuntu has it on by default). Linux and macOS are tested end-to-end in CI but not yet on many real desktops: reports are very welcome.
